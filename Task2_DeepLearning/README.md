# MLP Training for THA2 Dataset

This project provides various tools to train and experiment with Multi-Layer Perceptron (MLP) models for the THA2 binary classification task.

## 📁 File Overview

### Core Files

- **`MLP_Model.py`**: Core MLP model implementation
  - Supports customizable network architecture (number of hidden layers and neurons)
  - Provides Sigmoid and ReLU activation functions
  - Implements forward and backward propagation
  - Supports mini-batch SGD training

- **`Training.py`**: Complete training pipeline with hyperparameter experiments
  - Part A: Single model training and hyperparameter sweeps (learning rate, batch size, initialization scale)
  - Part B.1: Zero-initialization weight experiment
  - Part B.2: Learning rate × initialization variance heatmap analysis
  - Part B.3: Hidden layer activation visualization for best/worst models

- **`TrainingWithDiffHyperPara.py`**: Flexible hyperparameter grid search framework for Part B.4
  - Supports grid search over multiple hyperparameter combinations
  - Automatically generates Parallel Coordinates Plot
  - Provides detailed analysis of best/worst models
  - Overfitting/underfitting diagnosis

## 🚀 Quick Start

### 1. Basic Single Model Training

Use `Training.py` for standard training:

```bash
python Training.py
```

**Default Configuration:**
- Architecture: [10, 10] (two hidden layers with 10 neurons each)
- Learning rate: 0.01
- Batch size: 16
- Epochs: 200
- Activation function: Sigmoid

**Custom Configuration:** Edit the `CONFIG` dictionary in `Training.py` (around Line 650+):

```python
CONFIG = {
    'hidden_sizes': [20, 15, 10],  # Three hidden layers
    'learning_rate': 0.05,
    'batch_size': 32,
    'epochs': 300,
    'activation': 'relu',          # or 'sigmoid'
    'init_scale': 0.1,
}
```

### 2. Hyperparameter Grid Search

Use `TrainingWithDiffHyperPara.py` for large-scale experiments:

```bash
python TrainingWithDiffHyperPara.py
```

**Configuration:** Modify `MODE` and `hyperparameter_grid` at the bottom of the file:

```python
MODE = 2  # 1=single model, 2=grid search

# Grid search example
hyperparameter_grid = {
    'hidden_sizes': [[10, 10], [20, 15], [30, 20, 10]],
    'learning_rate': [0.001, 0.01, 0.1],
    'batch_size': [8, 16, 32],
    'activation': ['sigmoid', 'relu'],
    'init_scale': [0.01, 0.1, 0.5]
}
```

**Output Results:**
- `Plots/hyperparameter_results.csv`: All experiment results
- `Plots/parallel_coordinates.png`: Parallel coordinates plot (visualizing hyperparameter effects)
- `Plots/best_model_loss.png`: Best model training curves
- `Plots/worst_model_loss.png`: Worst model training curves

### 3. Advanced Experiments (Built-in Training.py)

**Part A - Hyperparameter Sweep:**
```python
# Configure SWEEP_MODE in Training.py
learning_rates = [0.001, 0.01, 0.05, 0.1]
batch_sizes = [8, 16, 32, 64]
init_scales = [0.01, 0.1, 0.5, 1.0]
```

**Part B.2 - Heatmap Analysis:**
- Explore the impact of learning rate × initialization variance on validation accuracy
- Automatically generates heatmap and marks the best combination

**Part B.3 - Activation Visualization:**
- Observe hidden layer neuron activations at initialization/mid-training/end of training
- Diagnose gradient vanishing or dead neuron problems

## 📊 Results Analysis

### Parallel Coordinates Plot Interpretation

The parallel coordinates plot generated by `TrainingWithDiffHyperPara.py` helps you:
- **Gray lines**: Hyperparameter configurations of all models
- **Colored lines**: Top-K best models (blue→red, low to high performance)
- **Key observations**: 
  - Position of best models on each parameter axis
  - Which hyperparameter combinations lead to high/low accuracy

### Overfitting/Underfitting Diagnosis

The program automatically analyzes:
- **Training accuracy vs validation accuracy gap**
- **Loss curve trends** (whether the second stage of training diverges)
- **Recommendations**: Adjust model complexity, regularization, or number of epochs

## 💡 Tips

1. **Random Seed**: The program uses `np.random.seed(42)` by default to ensure reproducibility
2. **Data Requirements**: Requires `THA2train.xlsx` and `THA2validate.xlsx` in the same directory
3. **CSV Columns**: Must contain `X_0`, `X_1`, `y` columns
4. **Batch Size**: If set to `None` or larger than training samples, automatically switches to full-batch gradient descent

**Note**: Use `Training.py` for standard training pipeline, and `TrainingWithDiffHyperPara.py` for large-scale hyperparameter search and analysis.
